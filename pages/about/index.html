About uSkyBlock

uSkyBlock is a Skyblock plugin for Minecraft servers. Players start on a small floating island, take on challenges with their friends, and grow it into a thriving island in the sky.

History

uSkyBlock's roots go back to skySMP, a GPLv3 plugin from October 2011 that brought Noobcrew's SkyBlock map to multiplayer servers. Talabrek's Ultimate SkyBlock for Bukkit built on it; he first released it as version 0.9.4 on 28 September 2012. By 2014 several versions were in circulation.

At the end of 2014 Talabrek gave rlf (R4zorax) the blessing to continue the project. rlf brought those versions together into one codebase and led it until 2018, with dutchy1001 writing code, guides and tutorials alongside. In January 2015 uSkyBlock got its own BukkitDev listing.

Muspah kept it going from 2018 to 2024, moved it into the uskyblock organisation on GitHub and published it on SpigotMC as uSkyBlock Revived.

minoneer has maintained uSkyBlock since 2024 and is rebuilding it for modern Minecraft and Paper.

Free and open source

uSkyBlock is licensed under the GNU GPLv3, and there is no paid version. The source code, the issue tracker and every release are on GitHub. Bug reports, translations and pull requests are always welcome, and the contributing guide shows how to get started.
